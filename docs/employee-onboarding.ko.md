# ENU Town 시작하기 (직원용)

ENU Town은 우리 사무실(대덕비즈센터 A동 606호)을 옮겨 놓은 사내 메타버스입니다.
팀들이 일하고 함께 일하는 모습을 보여 주는 **사무실 지도**라서, 캐릭터는 아무도 키로 조작하지 않습니다.
내 캐릭터 옆에는 나만의 작은 요정 펫이 따라다니며, **내 Claude가 써 준** 할 일 점검 문구를 나에게만 보여 줍니다.

## 1. ENU Town 로그인

1. 회사 Google 계정(@enu-tech.co.kr)으로 로그인합니다.
2. 개인정보 고지를 읽고 동의합니다. 고지가 바뀌면(현재 버전 2026-11) 다음 접속 때 다시 동의 화면이 나옵니다.
3. 내 자리를 확인합니다(이름이 명단과 같으면 자동으로 배정됩니다). 팀 자리는 ㄱ자 책상입니다.
4. 캐릭터(헤어·의상 색 등)와 펫을 고릅니다. 펫은 사람마다 다릅니다. 다른 동료가 이미 고른 펫은 선택 화면에
   표시되고 고를 수 없습니다.
5. "Claude 작업 대화 요약"을 동료에게 보여 줄지 정합니다(기본 비공개).
6. **활동 공유**를 정합니다. `공유하기` / `공유하지 않기` 중 하나를 직접 눌러야 하며, 미리 골라 둔 값은 없습니다.
   - 공유하기: 내 Claude가 보낸 회의·집중·부재 일정과 '지금 하는 일'의 종류가 근무 시간에 동료에게 보입니다
     (예: `회의 중 ~11:00 (캘린더 일정)`).
   - 공유하지 않기: 내가 직접 상태를 정했거나 타운을 열어 두었을 때만 보입니다.
   - 어느 쪽이든 타운을 열면 보통 내 아바타도 자리에 보입니다(서로 보기). 설정 > 접속 표시를 끄면 타운을 열어도
     보이지 않습니다.

이때 펫은 **잠들어 있습니다**(아직 Claude와 연결되지 않음).

## 2. 내 Claude와 연결

1. Claude 설정 > 커넥터 > **ENU Town**(사용자 지정) > **연결(Connect)**
2. 회사 Google 계정으로 로그인 → 동의 화면에서 **"Connecting as 내 이메일"** 을 확인하고 허용
3. ENU Town으로 돌아오면 펫이 깨어납니다.

## 3. 첫 체크인 + 예약 작업

1. Claude(Cowork)에 "ENU Town 체크인 해줘"라고 요청합니다. 승인 창이 뜨면 ENU Town 도구 다섯 가지를 모두
   **항상 허용**합니다.
2. ENU Town에서 내 업무 로그가 생겼는지 확인합니다(`/me` > 업무 로그의 "마지막 업데이트").
3. "ENU Town 설정 도와줘"라고 요청하면 `enu-town-setup` 스킬이 예약 작업 만들기를 안내합니다.
   권장: **매시간** 예약 작업 1개(근무 시간 밖 실행은 자동으로 건너뜀).

체크인 때 내 Claude는 업무 로그·할 일·펫 메시지를 쓰고, 활동 공유를 켰다면 오늘 업무 일정(회의·집중·부재)과
지금 하는 일의 종류도 보냅니다. 개인 일정과 면담 같은 인사 일정은 보내지 않고, 부재의 사유도 보내지 않습니다.

## 4. 화면 보는 법

- ENU Town이 내가 정한 상태, 타운 접속, (활동 공유를 켠 경우) 내 Claude가 보낸 캘린더 일정으로 자리에 앉히거나
  회의 테이블·동료 자리·탕비실로 옮깁니다. 내 Claude의 '지금 하는 일'과 오늘 업무 기록은 이름표나 자리 표시판에만
  붙습니다.
- **아바타의 위치와 움직임은 실제 위치가 아니라 업무 상태입니다.** 자리에 보이는 것은 출근·근무 시간을 뜻하지
  않고, 아바타가 없으면 '지금 알려진 활동이 없다'는 뜻일 뿐입니다.
- 이름표는 `무엇 · 출처` 모양입니다. 예: `회의 중 · 캘린더 일정 · ~11:00`, `집중 모드 · 직접 설정`,
  `검토 중 · Claude 보고`.
  - `Claude 보고`는 그 사람의 Claude가 최근 업무 흔적(문서·커밋·PR·리뷰)을 보고 판단한 지금 하는 일의 종류입니다.
    이것만으로 아바타가 나타나지는 않습니다.
- 아바타가 없는 자리의 표시판에는 이름만, 또는 `자리 비움 · ~15:00`이나 `부재`가 보입니다(`부재`에는 사유도
  끝나는 시각도 없습니다).
- 회의 테이블에 함께 있는 모습은 세 명 이상이 각자의 Claude로 같은 일정을 보고했을 때만, 동료 자리 옆에 선 모습은
  두 사람의 Claude가 같은 작업을 보고했을 때만 보입니다. 1:1 일정은 묶지 않습니다.
- 근무 시간(평일 08:30–19:30) 밖에는 누구의 상태도 보이지 않습니다. 채팅과 DM은 그대로 쓸 수 있습니다.
- 오른쪽 목록(좁은 화면에서는 사람 버튼)에 같은 내용이 글로 나옵니다. `접속 N명`은 지금 접속 중으로 표시된
  사람 수입니다(접속 표시를 끈 사람은 세지 않습니다).

| 전체 보기로 돌아가기  | `Esc`·`0` 키 또는 `전체 보기`                                                                                                                                                                                                         |

| 동료가 하는 일 보기   | 사람·자리 표시판·오른쪽 목록 클릭 > 지금 하는 일                                                                                                                                                                                      |
| 지난 대화 보기        | 사람 클릭 > 지난 대화 (우리 DM / 공개 채팅 / Claude 작업 대화 요약)                                                                                                                                                                   |
| 업무 요청             | 사람 클릭 > 업무 요청 (품질보증팀 → 검토 요청 등, DM 초안만 열림)                                                                                                                                                                     |
| 손 흔들기·부르기      | 사람 클릭 > 손 흔들기(모두에게 보여요) / 부르기(지금 접속 중인 사람에게만, 그 사람에게만 알림)                                                                                                                                        |
| 채팅                  | 채팅 창의 `전체` 또는 DM (말풍선은 화면에 보이는 사람 위에만 뜸)                                                                                                                                                                      |
| 내 상태               | 내 캐릭터나 내 자리 클릭 > `자동`·`대화 가능`·`집중 모드`·`회의 중`·`휴식`·`자리 비움`과 언제까지(`30분`·`1시간`·`2시간`·`오늘 근무 끝까지`, 기본 1시간). `자동`은 일정·Claude·업무 기록 기준으로 돌아가며, 상태 문구는 그대로 둡니다 |
| 활동 공유             | `/me` > 설정 > 활동 공유. 끄면 오늘 보고된 활동이 바로 지워집니다                                                                                                                                                                     |
| 접속 표시             | `/me` > 설정 > 접속 표시(기본 켜짐). 끄면 타운을 열어도 내 아바타와 접속 표시가 보이지 않습니다                                                                                                                                       |
| 펫이 보여 준 할 일    | 내 펫 클릭 > 할 일·메시지 목록, 완료/나중에/닫기                                                                                                                                                                                      |
| 내 로그 고치기·숨기기 | `/me` > 업무 로그 (직접 고친 로그는 Claude가 덮어쓰지 않음)                                                                                                                                                                           |
| 연결 끊기             | `/me` > 내 Claude 연결 > 해제                                                                                                                                                                                                         |

## 자주 묻는 질문

- **회사가 내 Claude 대화를 보나요?** 아니요. 내 Claude가 요약해 보낸 내용만, 내가 정한 공개 범위에서 보입니다.
- **펫 말풍선은 누가 보나요?** 나만 봅니다. 다른 사람에게는 말풍선이 떠 있다는 "…" 표시도 보이지 않습니다(말풍선은 내가 타운 탭을 보고 있을 때만 뜨므로, 표시가 있으면 내가 화면을 보는 시각이 드러나기 때문입니다).
- **내 아바타가 안 보여요.** 상태를 정하지 않았고, 타운을 열지 않았고(또는 접속 표시를 껐고), 지금 회의·집중
  일정도 없으면 자리 표시판에 이름만 보입니다. 내 상태를 정하면 바로 자리에 보입니다. 캘린더에 부재 일정이 있으면
  타운을 열어도 `부재`로만 보입니다.
- **휴가 중에 타운을 봐도 되나요?** 네. 캘린더 부재 일정이 있으면 `부재`로만 보이고, 접속 표시를 끄면 타운을 열어도
  보이지 않습니다.
- **다른 사람의 Claude가 내 아바타를 옮길 수 있나요?** 아니요. 각자의 Claude는 자기 일정과 활동만 보내고 동료
  이름은 쓰지 않습니다. 함께 있는 모습은 각자의 Claude가 같은 일정이나 작업을 **각각** 보고했을 때만 보입니다.
- **출근 확인이나 성과 평가에 쓰이나요?** 아니요. 업무 공유 목적이며 근태 확인·성과 평가·징계 자료로 쓰지
  않습니다. 접속·위치·상태의 이력은 저장하지 않으므로 관리자도 볼 수 없습니다.
- **퇴근 후에도 펫이 말하나요?** 아니요. 근무 시간 밖(19:30–08:30)과 주말·공휴일에는 항상 조용합니다. 근무 시간
  중에도 펫 설정에서 조용한 시간을 정할 수 있습니다.
