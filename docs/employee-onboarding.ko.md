# ENU Town 시작하기 (직원용)

ENU Town은 우리 사무실(대덕비즈센터 A동 606호)을 옮겨 놓은 사내 메타버스입니다.
내 캐릭터 옆에는 작은 요정 펫이 따라다니며, **내 Claude가 써 준** 할 일 점검 문구를 나에게만 보여 줍니다.

## 1. ENU Town 로그인

1. 회사 Google 계정(@enu-tech.co.kr)으로 로그인합니다.
2. 개인정보 고지를 읽고 동의합니다.
3. 내 자리를 확인합니다(이름이 명단과 같으면 자동으로 배정됩니다).
4. 캐릭터(헤어·의상 색 등)와 펫(고양이·토끼·여우·병아리·햄스터·아기용)을 고릅니다.
5. "Claude 작업 대화 요약"을 동료에게 보여 줄지 정합니다(기본 비공개).

이때 펫은 **잠들어 있습니다**(아직 Claude와 연결되지 않음).

## 2. 내 Claude와 연결

1. Claude 설정 > 커넥터 > **ENU Town**(사용자 지정) > **연결(Connect)**
2. 회사 Google 계정으로 로그인 → 동의 화면에서 **"Connecting as 내 이메일"** 을 확인하고 허용
3. ENU Town으로 돌아오면 펫이 깨어납니다.

## 3. 첫 체크인 + 예약 작업

1. Claude(Cowork)에 "ENU Town 체크인 해줘"라고 요청합니다. 승인 창이 뜨면 ENU Town 도구를 **항상 허용**합니다.
2. ENU Town에서 내 업무 로그가 생겼는지 확인합니다(프로필 카드의 "마지막 업데이트").
3. "ENU Town 설정 도와줘"라고 요청하면 `enu-town-setup` 스킬이 예약 작업 만들기를 안내합니다.
   권장: **매시간** 예약 작업 1개(근무 시간 밖 실행은 자동으로 건너뜀).

## 4. 쓰는 법

| 하고 싶은 일 | 방법 |
|---|---|
| 이동 | WASD/방향키 또는 바닥 클릭 |
| 동료가 하는 일 보기 | 캐릭터(또는 빈 책상) 클릭 > 지금 하는 일 |
| 지난 대화 보기 | 캐릭터 클릭 > 지난 대화 (우리 DM / 함께 들은 근처 대화 / 공개 채팅 / Claude 작업 대화 요약) |
| 업무 요청 | 캐릭터 클릭 > 업무 요청 (품질보증팀 → 검토 요청 등, DM 초안만 열림) |
| 펫이 보여 준 할 일 | 내 펫 클릭 > 할 일·메시지 목록, 완료/나중에/닫기 |
| 내 로그 고치기·숨기기 | `/me` > 업무 로그 (직접 고친 로그는 Claude가 덮어쓰지 않음) |
| 연결 끊기 | `/me` > 내 Claude 연결 > 해제 |

## 자주 묻는 질문

- **회사가 내 Claude 대화를 보나요?** 아니요. 내 Claude가 요약해 보낸 내용만, 내가 정한 공개 범위에서 보입니다.
- **펫 말풍선은 누가 보나요?** 나만 봅니다. 다른 사람에게는 펫 머리 위 "…" 표시만 보입니다.
- **성과 평가에 쓰이나요?** 아니요. 업무 공유 목적입니다.
- **퇴근 후에도 펫이 말하나요?** 아니요. 19:30–08:30, 주말·공휴일에는 조용합니다(펫 설정에서 조정 가능).
