# ENU Town 개인정보 처리 고지 (버전 2026-10)

> 이 문서는 초안입니다. 시행 전 인사·법무 검토를 받으세요(근로자 감시 설비 해당 여부와 노사협의 필요성 포함).
> 웹의 `/privacy` 페이지와 같은 내용을 유지하고, 바뀌면 `PRIVACY_NOTICE_VERSION`을 올려 재동의를 받습니다.

## 목적
사내 업무 공유와 협업(누가 무엇을 하는지, 다음에 할 일 점검). **성과 평가에 사용하지 않습니다.**

## 수집 항목
| 항목 | 출처 | 기본 공개 범위 |
|---|---|---|
| 이름, 회사 이메일, 프로필 사진(Google) | Google 로그인 | 사내 |
| 자리, 팀·직위·역할 | 관리자가 등록한 좌석 명단 | 사내 |
| 업무 로그(요약·작업·막힌 점) | **본인의 Claude**가 작성 | 사내(본인이 로그마다 비공개로 변경 가능) |
| Claude 작업 대화 요약 | **본인의 Claude**가 작성 | **본인이 공개를 선택한 경우에만** 사내 |
| 할 일, 펫 메시지 | 본인의 Claude가 작성 | 본인만 |
| 타운 채팅(근처·전체·DM) | 직원 입력 | 받은 사람 |
| 접속 위치·상태, 감사 기록(내용 제외) | 시스템 | 관리자(감사), 사내(접속 상태) |

## 수집하지 않는 것
- **Claude 대화 원문** — 수집하지 않습니다. 회사는 Claude Enterprise Compliance API를 ENU Town에 사용하지 않습니다.
- Claude 계정 비밀번호·토큰 — ENU Town은 Claude에 로그인하지 않습니다.

## 데이터 흐름
- ENU Town 도구 결과(내 할 일, 내 로그, (선택 시) 나에게 온 DM)는 **내 Claude**(Anthropic, 회사 Claude 계약)로 전달됩니다.
- 나에게 온 DM을 내 Claude가 읽는 기능은 **기본 꺼짐**이며 본인이 켤 수 있습니다.

|---|---|

| 펫 메시지·표시 기록 | 14일 |
| 감사 기록(내용 없음) | 365일 |
