# 공개 기준 상세 (ENU Town 업무 로그·펫 문장)

업무 로그는 기본 **전사 공개**, 펫 문장은 **본인만** 보지만 둘 다 같은 기준을 지킨다.
ENU Town 서버도 주민번호·전화번호·카드번호·계좌번호·링크를 감지하면 **거부**한다(고쳐 쓰지 않음).

| 쓰지 않는 것 | 나쁜 예 | 좋은 예 |
|---|---|---|
| 개인정보 | "홍길동 010-1234-5678에게 회신" | "발주처 담당자에게 회신" |
| 고객·발주처 민감 정보 | "KNF 김OO 부장과 3억 견적 협의" | "발주처와 견적 범위 협의" |
| 인사 정보 | "OO님 휴직 사유 정리" | (쓰지 않음) |
| 비밀값·내부 주소 | "DB 비밀번호 변경 pw=..." / "http://10.0.0.5/admin" | "DB 접근 권한 정리" |
| 원문 인용 | "메일: '이번 주까지 꼭 ...'" | "이번 주 마감 요청 메일 확인" |
| 타인 평가 | "OO님 코드 품질이 낮아서 재작업" | "코드 리뷰 의견 반영" |
| 링크 | "https://github.com/... PR 머지" | "PR ENU-142 머지" (`ref: "ENU-142"`) |

애매하면:
1. 해당 문장을 빼거나 일반화한다.
2. 그래도 필요하면 `post_work_log`의 `visibility: "private"`로 보낸다.

`claude_chat_summary`는 "무엇에 대해 이야기했는지"만 쓴다. 대화 원문, 사적인 상담,
다른 사람에 대한 이야기는 쓰지 않는다. 사용자가 이 요약을 공개하기로 선택하지 않았다면
서버가 자동으로 비공개로 저장한다.
