# 공개 기준 상세 (ENU Town 업무 로그·펫 문장·활동)

업무 로그는 기본 **전사 공개**, 펫 문장은 **본인만** 보지만 둘 다 같은 기준을 지킨다.
ENU Town 서버도 주민번호·전화번호·카드번호·계좌번호·링크를 감지하면 **거부**한다(고쳐 쓰지 않음).

| 쓰지 않는 것          | 나쁜 예                                             | 좋은 예                              |
| --------------------- | --------------------------------------------------- | ------------------------------------ |
| 개인정보              | "홍길동 010-1234-5678에게 회신"                     | "발주처 담당자에게 회신"             |
| 고객·발주처 민감 정보 | "KNF 김OO 부장과 3억 견적 협의"                     | "발주처와 견적 범위 협의"            |
| 인사 정보             | "OO님 휴직 사유 정리"                               | (쓰지 않음)                          |
| 비밀값·내부 주소      | "DB 비밀번호 변경 pw=..." / "http://10.0.0.5/admin" | "DB 접근 권한 정리"                  |
| 원문 인용             | "메일: '이번 주까지 꼭 ...'"                        | "이번 주 마감 요청 메일 확인"        |
| 타인 평가             | "OO님 코드 품질이 낮아서 재작업"                    | "코드 리뷰 의견 반영"                |
| 링크                  | "https://github.com/... PR 머지"                    | "PR ENU-142 머지" (`ref: "ENU-142"`) |

애매하면:

1. 해당 문장을 빼거나 일반화한다.
2. 그래도 필요하면 `post_work_log`의 `visibility: "private"`로 보낸다.

`claude_chat_summary`는 "무엇에 대해 이야기했는지"만 쓴다. 대화 원문, 사적인 상담,
다른 사람에 대한 이야기는 쓰지 않는다. 사용자가 이 요약을 공개하기로 선택하지 않았다면
서버가 자동으로 비공개로 저장한다.

## 활동(post_activity)에서 빼는 것

`post_activity`에는 글을 쓰는 필드가 없다. 대신 **어떤 일정을 보내는지, 어떤 일정에 `ref`를 붙이는지**가 공개 기준이다.
회의·집중·부재와 '지금 하는 일'은 근무 시간에 동료에게 사무실 지도로 보인다.

| 일정·활동                               | 보내는 법                                                                                        |
| --------------------------------------- | ------------------------------------------------------------------------------------------------ |
| 참석자 3명 이상(나 포함)의 업무 회의    | `kind: "meeting"`, `ref: "gcal:<iCalUID>"`                                                       |
| 1:1 일정(참석자 2명)                    | `kind: "meeting"`, **`ref` 없이** (둘이 함께 있는 모습으로 그려지지 않는다)                      |
| 면담·평가·채용·징계 등 인사 관련 일정   | **보내지 않는다**(`ref` 없는 회의로도 보내지 않는다)                                             |
| 개인 일정(병원·가족·은행·학교 등)       | **보내지 않는다**                                                                                |
| 휴가·반차·외근·출장·부재중              | `kind: "away"`만. 사유(휴가 종류, 병원, 경조사 등)는 업무 로그를 포함해 **어디에도 쓰지 않는다** |
| 거절·미정·미응답 일정, 알림용 종일 일정 | 보내지 않는다                                                                                    |
| 제목·참석자·장소                        | 보낼 필드가 없다. 일정 제목을 `ref`나 다른 곳에 넣지 않는다                                      |
| 동료 이름·이메일                        | 어떤 필드에도 쓰지 않는다. 누구와 함께 있는지는 ENU Town이 각자의 Claude가 보낸 `ref`로만 정한다 |
| `ref`                                   | 도구가 준 ID를 **그대로**. 지어내거나 추측해서 맞추지 않는다                                     |

애매한 일정은 보내지 않는다. 보내지 않아도 사용자가 직접 정한 상태와 타운 접속으로 자리에 보일 수 있다.
